# 💰 Planificador de Gastos (con Context API)

Aplicación web interactiva desarrollada en **React + TypeScript** que permite gestionar un presupuesto personal.  
Se pueden añadir gastos, editarlos, eliminarlos y visualizarlos en gráficos dinámicos.
  
---

## 🚀 Tecnologías utilizadas
- React + Vite
- TypeScript
- Context API + useReducer
- TailwindCSS
- LocalStorage
- Librerías externas:
  - `uuid`
  - `react-date-picker`
  - `react-circular-progressbar`
  - `react-swipeable-list`

---

## ⚡ Funcionalidades
- Definir un presupuesto inicial.
- Añadir, editar y eliminar gastos.
- Filtrar gastos por categorías.
- Persistencia con LocalStorage.
- Gráfica de progreso interactiva.
- Interfaz responsive y moderna con TailwindCSS.
